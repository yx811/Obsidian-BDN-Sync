# BDNSync v1.0.8 发布说明

> 最低 Obsidian 版本：`1.13.7`
> 上一个版本：v1.0.7

BDNSync 是一个把 Obsidian vault 与百度网盘双向同步的第三方插件，提供保存即同步、三向冲突自动合并、端到端加密、断点续传、整库快照回滚，并支持在 Obsidian 内直接浏览与直嵌网盘文件。

---

## 本次更新亮点

v1.0.8 是一次「同步触发可靠性 + 完整功能验收 + 性能 + 界面重构」的集中治理版本。核心是解决三类用户可感知的问题：**点了同步没反应 / 重开后不同步 / 保存了不上传**；在全量走查中修复了状态机死锁、资源锁泄漏、弹窗悬挂等一批静默缺陷；对同步对比阶段做了并发化与缓存复用；并对状态栏、同步日志浏览器、设置页连接卡、冲突面板、统计图表等区域做了系统性视觉重构（样式源码由 105 行扩充到 2,457 行）。

### 同步触发时机（🔴 重点修复）

| 项目 | 说明 |
| --- | --- |
| 触发边界收敛为单一事实来源 | 此前「是否自动触发」散落在 5 个入口，各自重复判断模式，导致 `auto` 与 `realtime` 都触发了「保存即同步」。现由 `src/sync/trigger-policy.ts` 的纯函数统一查表，并新增触发策略矩阵单测。 |
| 重开 / 重载不再跳过启动同步 | 两处叠加导致「重载/重开后不自动同步」：(a) 启动同步要求勾选「启动时同步」，`auto` / `realtime` 用户未必勾选该项；(b) 会话中启用插件时 `skipStartupSync` **直接跳过**。现改为：`auto` / `realtime` 无论该开关都触发；`skipStartupSync` 不再跳过，而是延迟约 12 秒执行。 |
| 手动触发不再「只转图标不执行同步」 | 引擎正忙时点击同步原本**静默放弃**。现置位排队，当前同步结束后自动补做一次，并提示「本次点击已排队」。 |
| 点击同步有即时反馈 | Ribbon / 命令 / 状态栏三个入口统一：立刻置状态栏为「同步中」；若本次无变更则明确提示「已是最新，无需同步」。 |
| 调度热生效 | 「同步模式 / 自动同步间隔」改动保存后立即重算下次自动同步时间，无需重载。 |
| 离线与未初始化不再静默 | 离线提示「恢复网络后自动同步」；引擎未初始化时提示检查设置后重载。 |

### 数据安全与可靠性

| 项目 | 说明 |
| --- | --- |
| 实时同步丢改动（🔴 数据安全） | ① 同步期间产生的变更被 `clearTimer` 直接丢弃 → 改为重新投递回批次队列；② 批次触发时「先清空再判断挂起」导致累积变更永久丢失 → 改为挂起时原样保留；③ >100MB 超大文件被 `return` 静默丢弃、永远不会同步 → 改为降级为一次完整同步；④ 重试间隔复用了入口处的旧时间戳 → 改用当前真实时间戳。 |
| 状态栏永久卡「同步中」（🔴 状态机死锁） | `setIdle()` 的自保守卫与 `setSyncing()` 形成死锁，导致 6 条取消路径（取消预览 / 取消同步 / 首同步取消 / 删除保护取消等）状态栏永久转圈 —— 而错误路径正常。新增 `forceIdle()` 作为统一收口。 |
| 预览锁泄漏（🔴） | `previewPanel = false` 写在 `await modal.show()` 之前，弹窗等待期间锁是开的（可重复触发、弹窗叠加），且 `show()` 抛错时锁永久为 `true`、之后无法手动同步。改用 `try/finally` 包裹完整作用域。 |
| 预览弹窗 Promise 悬挂（🔴） | `open()` 抛错时 `onClose` 不触发、Promise 无人 resolve，调用方 `await` 永久挂起。已加 `try/catch` 兜底。 |
| 统计图表 SVG/HTML 注入（🔴 安全） | `buildStatsSvgs()` 把用户可控数据（文件扩展名等）直接拼进 `innerHTML`，已补 `escHtml()` 实体转义。 |
| 其它 | 卸载后弹窗遮罩残留、`StatusBar.unmount()` 未清定时器、日志订阅退订误伤同引用监听、本地索引清单无类型校验、写盘前备份读取（TOCTOU）阻断写入、每次保存设置都重建后端、配额刷新无并发去重、设置页容器脱离文档后仍渲染。 |

## 从 v1.0.7 升级请务必了解（行为变更）

### ⚠️ 默认同步模式由 `manual` 改为 `realtime`

- **已安装用户不受影响**：`syncMode` 已持久化在你的配置中，升级后仍保持原值。
- **新装用户**：开箱即用（保存即同步 + 重开/启动必触发 + 周期兜底对账），不再出现「装完什么都没在同步」。
- 如需保持纯手动：设置 → 同步设置 → 同步模式改为「手动模式」。

### ⚠️ 自动模式（auto）不再「保存即同步」

这是对既有语义的**修正**：v1.0.7 及更早版本中 `auto` 与 `realtime` **都**会触发保存即同步，两个模式的边界名存实亡。v1.0.8 起：

- `realtime`：保存即同步（+ 周期对账 + 启动/网络恢复兜底）
- `auto`：**仅**周期对账（+ 启动/网络恢复兜底），保存的变更由下一个周期的全量扫描覆盖
- `manual`：完全手动

> 如果你此前使用 `auto` 并依赖「保存后立即上传」，请改为 `realtime`。

### ⚠️ 实时模式防抖档位收紧

| 场景 | v1.0.7 | v1.0.8（realtime） |
| --- | --- | --- |
| 普通文件防抖 | 3 秒 | **800 毫秒** |
| 大文件（>10MB）防抖 | 10 秒 | **3 秒** |
| 批次合并窗口 | 5 秒 | **1.5 秒** |

`auto` / `manual` 维持原档位（3s / 10s / 5s）。切换同步模式时档位即时生效，无需重载。

### ⚠️ 其它行为调整

- **推迟的增量兜底对账不再弹预览框**：改为以 `auto` 语义执行。此前开启「同步预览」时，每次完整同步结束都会莫名再弹一次确认框。
- **同步预览计算期间显示进度**：此前静默执行、大库下长时间无反馈。现在底部状态栏按阶段实时显示（读取云端索引 → 列出云端文件清单 → 扫描本地文件），最终仍弹出原有的居中确认弹窗（样式与位置不变）。
- **日志视图结构重组**：底栏左右分区（左侧清空 / 复制全部日志 / 复制诊断，右侧「导出」下拉收纳 JSON / 文本 / CSV / Markdown）；新增日期区间筛选与搜索框一键清除。原有搜索（含正则）、排序、实时订阅、四种导出格式均保持不变。

## 已知限制与待确认

1. **需真实百度凭据的在线场景**（授权 / 上传 / 下载 / 在线预览）依赖真实账号，自动化测试无法覆盖，需在 Obsidian 内人工验收。
2. **Office 文档在线预览**（`.docx` / `.xlsx` / `.pptx`）使用 `iframe` 嵌入，依赖 WebView 的 Cookie 罐，实际可用性较脆弱。
3. **设备码授权的二维码**：优先使用百度官方返回的 `qrcode_url`；仅在其缺失时回退第三方生成服务，且加载失败会自动降级为手动输入授权码。
4. **Git 增量同步**、**局域网 P2P 同步**、**功能自检**为实验室功能，默认关闭；其中 Git 与局域网 P2P 仅桌面端可用。
5. **「扫描并发数」的新用途（待确认）**：该设置现同时用于孤儿扫描与远端目录树并发遍历（默认 3、上限 8）。在超大库下调高该值对百度接口限频的具体影响**尚未在真实环境验证**，建议保持默认 3 并根据实际表现微调。

## 安装与升级

### 从社区插件市场安装

1. Obsidian 设置 → 第三方插件 → 关闭「安全模式」
2. 浏览社区插件市场，搜索 **BDNSync**
3. 安装并启用

### 手动安装

从 GitHub Releases 下载 `manifest.json`、`main.js`、`styles.css`，放入 `<vault>/.obsidian/plugins/bdnsync/` 后启用插件。

### 升级建议

- 从 v1.0.7 升级：无破坏性数据变更，直接覆盖即可。**升级后请确认一件事情** —— 如果你使用「自动模式」并依赖保存即上传，请改为「实时模式」（见[行为变更](#从-v107-升级请务必了解行为变更)）。
- 从 v1.0.5 或更早升级：仍请先按 v1.0.7 的说明校验「端到端加密」配置（若你只填了密钥文件路径而未填密码，那些版本中文件可能是明文上传的）。
