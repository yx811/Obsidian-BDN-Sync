# BDNSync v1.0.7 发布说明

> 发布日期：2026-08-29
> 最低 Obsidian 版本：`1.13.7`
> 上一个版本：v1.0.6

BDNSync 是一个把 Obsidian vault 与百度网盘双向同步的第三方插件，提供保存即同步、三向冲突自动合并、端到端加密、断点续传、整库快照回滚，并支持在 Obsidian 内直接浏览与直嵌网盘文件。

---

## 一、本次更新亮点（v1.0.7）

v1.0.7 是围绕「插件稳定性、数据安全与可维护性」的一次集中加固版本，覆盖从 v1.0.6 起的稳定性修复、全面质量验收修复与遗留非阻断问题收尾，共 18 项（生命周期稳定性 5 项、🔴 数据安全 / 可靠性 6 项、🟡 界面与构建 6 项、收尾 7 项中的关键项）。

### 生命周期与交互稳定性（修复「启用后设置弹窗自关 / 反复需重新启用 / 界面不稳定」）

| 项目 | 说明 |
| --- | --- |
| 设置弹窗不再被强制关闭（主因） | `syncNow()` / `runQuickSync()` 原本**无条件**调用 `app.setting.close()`，导致启用插件或保存笔记时设置页被当场关闭。现改为仅在确实要弹出 Modal 时才关闭设置页。 |
| 会话中启用不再抢占 UI | 注册 `onLayoutReady` 时用 `registrationDone` 判定是否「会话中手动启用」，是则传 `skipStartupSync: true` 跳过启动同步，避免抢占你正在配置的设置页。 |
| 不再需要反复重新启用 | `onload()` 改为三段式（设置兜底 → **设置页最先注册** → 子系统隔离），任一子系统抛错只降级该功能、记日志，不再拖垮整体加载、逼你反复开关插件。 |
| 消除未处理的 Promise rejection | `onLayoutReady` / 日志清理 / 重试队列 / 在线同步等裸 `void` 调用全部补 `.catch`，消除「页面不稳定」的常见诱因。 |
| 定时器托管修正 | API 探查的 15s 延迟启动由误用的 `registerInterval(setTimeout)` 改为 `register(() => clearTimeout(id))`，避免类型误用导致的泄漏。 |

### 数据安全与可靠性

| 项目 | 说明 |
| --- | --- |
| 密钥文件模式未接线 → 静默明文上传（🔴 数据安全） | `resolveEncryptionPassword()` 此前**全仓零调用**，开启加密却只填密钥文件路径、密码留空时文件会**明文上传且无提示**。现已接入异步密钥解析并缓存，解析失败记录醒目告警，杜绝「以为加密了实则明文」。 |
| 重试队列退避与上限失效 → 无限重试（🔴） | `flush()` 提前移除条目导致重试次数恒为 1、`MAX_ATTEMPTS`(8) 永不触达。现引入跨周期次数记忆 `attemptsMemo`，超限即放弃并告警；成功出队由 `markSuccess()` 显式闭环。 |
| 接口 / 通信健壮性 | 修复「静默假空」高危缺陷（`safeJson` 返回 `null` 被误判成功，可能把远端目录误判为空、进而误删本地文件）、OpenAPI POST 缺 `Content-Type`、分片上传 token 过期不刷新等 4 处。 |
| 取消同步能力落地 | `engine.cancel()` 此前从未被调用，6 处中止守卫全部不可达。现新增命令「BDNSync：取消当前同步」，在阶段 / 文件边界安全中止（不会在写盘或网络请求中途硬切）。 |
| 跨批次重命名配对 | `matchRename()` 此前是死代码且语义有误；现已接入并修正 —— 命中后把 old / new **双双加回脏集合**（而非移除 oldPath），由引擎按内容 hash 判定为 move，保留云端 fsId、避免整文件重传与远端残留。 |

### 界面与构建可维护性

| 项目 | 说明 |
| --- | --- |
| 孤儿清理弹窗样式缺失（🔴） | TypeScript 使用 37 个 `bdnsync-orphan-*` 类，样式表仅覆盖 15 个，主入口弹窗排版塌陷。已一次性补齐，统一沿用设计令牌与主题变量。 |
| 构建产物覆盖样式源码（🔴 可维护性） | 生产构建把压缩后的 CSS 复制回被 `main.ts` 导入的**源码** `styles.css`，一度摧毁手写样式。现源码迁至 `src/styles.css`，构建加安全阀校验源码存在（缺失即报错退出）。 |
| 会员等级配色不生效（🟡） | TS 拼出的连写类名与 CSS 两个类定义不匹配，金色 / 蓝色会员配色失效。已改为独立状态类，并补上此前无样式的 `.bdnsync-vip-tier`。 |
| 可点击路径 / 减弱动效（🟡） | 补日志路径 `cursor:pointer` 与虚线下划线；`prefers-reduced-motion` 补齐 `hub-pulse` / `shimmer` / `blink` / `pulse` / `vip-warn` / `modal-in` / `orphan-scan-spinner` 等无限循环动画。 |
| API 探查热生效 | 探查调度抽出 `restartApiProbe()`，于设置保存时重建并热生效；用 `lastApiProbeAt` 做启动限频，改设置后无需重载插件。 |
| 看板轮询打磨 | 跨设备看板后台标签页（`document.hidden`）跳过重绘，重绘前后保存 / 恢复 `scrollTop`，不再丢滚动、不打断文本选择。 |
| 无障碍与死代码清理 | 媒体播放器 15 个图标按钮补 `aria-label`；孤儿清理「手动录入」行补 `flex-wrap` 防窄屏溢出；看板画布补 `overflow-y: auto`；删除 705 行死代码 `src/ui/netdisk-browser.ts`。 |

## 二、从 v1.0.5 升级请务必了解（数据安全提示）

如果你此前使用的是 v1.0.5 或更早版本，并开启了「端到端加密」但**只填了密钥文件路径、未填密码**，那些版本中文件可能是**明文上传的**（密钥文件模式从未被接线）。v1.0.7 已修复该问题：

- 升级后请到设置页重新校验一次加密状态，确认密钥文件可被正确解析；
- 若解析失败，插件会给出醒目告警，而不会再「以为加密了实则明文」。

此外，v1.0.7 还修复了重试队列无限重试（永久失败项每 15s 空耗 API 配额）与「静默假空」可能误删本地文件的高危缺陷，建议尽快升级。

## 三、已知限制

1. **需真实百度凭据的在线场景**（授权 / 上传 / 同步 / 在线预览）依赖真实账号，自动化测试无法覆盖，需在 Obsidian 内人工验收。
2. **Office 文档在线预览**（`.docx` / `.xlsx` / `.pptx`）使用 `iframe` 嵌入，依赖 WebView 的 Cookie 罐，实际可用性较脆弱。
3. **设备码授权的二维码**：优先使用百度官方返回的 `qrcode_url`；仅在其缺失时回退第三方生成服务，且加载失败会自动降级为手动输入授权码。
4. **Git 增量同步**与**局域网 P2P 同步**为实验室功能，仅桌面端可用，默认关闭。

## 五、安装与升级

### 从社区插件市场安装

1. Obsidian 设置 → 第三方插件 → 关闭「安全模式」
2. 浏览社区插件市场，搜索 **BDNSync**
3. 安装并启用

### 手动安装

从 GitHub Releases 下载 `manifest.json`、`main.js`、`styles.css`，放入 `<vault>/.obsidian/plugins/bdnsync/` 后启用插件。

### 升级建议

- 从 v1.0.5 或更早升级：请重点确认「端到端加密」配置 —— 若你此前只填了密钥文件路径而未填密码，**v1.0.5 及更早的文件可能是明文上传的**。升级到 v1.0.7 后可在设置页重新校验加密状态。
- 从 v1.0.6 升级：无破坏性变更，直接覆盖即可。
