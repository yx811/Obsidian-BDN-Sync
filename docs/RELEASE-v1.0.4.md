# BDNSync v1.0.4 发布说明

> 发布日期：2026-08-26  
> 最低 Obsidian 版本：1.13.7

---

## 新增：跨设备同步看板（独立标签页）

- 将原本的弹窗式聚合表格升级为**独立 Obsidian 工作区标签页**（ItemView），可与笔记并列/拖拽、常驻查看。
- 命令面板新增「跨设备同步状态看板」，一键打开标签页。
- 看板展示三类信息：
  - **云端状态**：连接/未连接徽标、百度网盘账号名、配额占用 SVG 环形图、上次同步时间。
  - **本机在线状态**：工具栏实时显示本机在线/离线，并监听网络状态变化即时更新。
  - **所有设备**：卡片展示设备名（本机高亮）、文件数、占用、最近活跃；远端设备活跃度基于最近同步时间推测并明确标注。
- 底部汇总栏：总文件数 / 总占用 / 在线设备。

## 视觉：画布式拓扑 + 中式审美 + 主题自适应

- 画布式拓扑布局：云端作为中心枢纽，设备以视觉卡片网格分布。
- 中式审美配色：霁蓝 / 竹青 / 朱砂 / 琥珀等低饱和传统色系。
- 全彩视觉元素：云端圆环徽标、SVG 环形配额图、设备平台图标、状态色边条、本机高亮。
- 主题自适应：关键色跟随 Obsidian 主题变量，卡片/工具栏使用主题背景变量，深色与浅色主题均自然融入。
- 响应式：桌面端多列网格；移动端 ≤720px 单列；≤420px 隐藏标题文字并纵向堆叠指标。

## 安全与健壮性加固

- `SyncEngine.writeLocalFile` 新增路径穿越守卫，拒绝含 `..` 段的相对路径。
- `redactSecrets` 词表补入 `encryptionPassword`，日志脱敏更完整。
- 收紧多处 `as any` 类型逃逸，改为精确接口。
- 启动后 API 探查改用 `registerInterval` 托管，确保卸载时自动清理。
- `onunload` 增强：关闭跨设备看板标签页、清理反向引用重建定时器、移除状态栏 DOM。
